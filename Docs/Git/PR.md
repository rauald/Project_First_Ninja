# Pull Request 규칙

- PR 생성 권한은 `Docs/Git/GitWorkflow.md`를 따른다.
- 소스 브랜치와 대상 브랜치를 확인한다. 대상이 미정이면 사용자에게 확인한다.
- 기본 생성 상태는 Draft로 한다.
- 제목과 본문은 한국어로 작성한다.

## 본문 양식

### 변경 내용
- 변경한 내용과 이유를 적는다.

### 검증
- 실제로 실행한 검증과 결과를 적는다.
- 실행하지 못한 필수 검증은 이유와 함께 적는다.

### 관련 이슈
- 연결할 이슈가 있을 때 적는다.

### 확인이 필요한 항목
- 리뷰어가 확인해야 할 동작, 설정 또는 미해결 항목을 적는다.
