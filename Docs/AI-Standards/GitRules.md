# Git 공통 작업 규칙

> 이 파일은 Git 공통 규칙으로 사용한다.

---

## 작업 전 확인

- Git 저장소 여부, 현재 브랜치, 작업 트리 상태를 확인한다.
- `ProjectInstructions.md`에 따라 적용되는 `AI-Standards` 문서를 모두 읽은 뒤, 실제 Git 작업을 할 때 `Docs/Git/GitWorkflow.md`에서 작업 순서, 실행 권한, 세부 문서를 확인한다.


## 완료 보고

- 공통 완료 보고에 실제 수행한 Git 작업을 덧붙인다.
- 해당하는 경우 브랜치, 커밋, push, 이슈, PR 상태를 기록한다.
