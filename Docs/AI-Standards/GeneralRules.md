# 공용 원칙

## 작업 원칙
- Unity 버전과 설치된 패키지를 확인한다.
- 기존 프로젝트의 개발 방식을 우선 확인한다.
- 새 프로젝트 초기화를 요청받았을 때 아래 구조를 기준으로 필요한 기본 폴더를 만든다. 
- 기본 폴더를 제외하고, 기존 프로젝트에서는 현재 구조를 확인하고 작업에 필요한 폴더만 추가한다.
```
Assets ← 최상위 폴더
ㅣ- 01_Scenes
ㅣ- 02_Scripts
ㅣ- 03_Prefabs
ㅣ- 04_Arts
ㅣ  ㅣ- 00_Image
ㅣ  ㅣ- 01_Material
ㅣ  ㅣ- 02_Texture
ㅣ- 05_Models
ㅣ- 06_Sounds
ㅣ- 07_Animations
ㅣ- 08_Effects
ㅣ- 09_Shader
ㅣ- 99_Etc
```
## 초기 설정 진행

- 이 문서는 새 프로젝트의 초기 설정을 요청받았을 때 적용한다.
- `Docs/ProjectOverview.md`에 기록된 Unity 버전, 렌더 파이프라인,
  입력 시스템, 주요 패키지를 확인한다.
- Unity 프로젝트가 이미 있다면 현재 설정과 폴더 구조를 먼저 확인한다.
- 위 폴더 목록을 기준으로 이번 프로젝트에 필요한 폴더와 변경할 설정을 정리한다.
- 폴더 생성, 설정 변경, 패키지 설치는 사용 중인 AI의 프로젝트 지침에 있는
  승인 기준을 따른다.

## 초기 설정 검증과 보고

- 요청 범위에 포함된 폴더와 설정이 의도한 대로 반영됐는지 확인한다.
- Unity를 실행할 수 있으면 프로젝트가 열리는지 확인하고, 확인한 오류를 기록한다.
- 실제로 생성한 폴더, 변경한 설정, 설치한 패키지를 보고한다.
- 확인하지 못한 항목은 그 이유와 함께 기록한다.
