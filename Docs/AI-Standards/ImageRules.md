# 이미지 규칙

## 생성 규칙

> 이미지 생성 시 이미지 크기는 아래 규칙을 따른다.

- 이미지 크기는 전체 배경은 2048x2048 / 그 외에는 1024x1024 를 초과하지 않는다.
- 이미지 크기는 최대한 정사각형으로 만든다. (단, 전체 배경은 직사각형으로 만든다.)
- 모든 이미지 크기는 가로, 세로 모두 2진법 크기로 한다.
- 스프라이트 시트는 아래 내용으로 정의한다.
    ```markdown
    스프라이트 시트는 왼쪽에서 오른쪽으로 / 위에서 아래로 채운다.
    스프라이트 시트는 총 4종류가 있다.
    1. 캐릭터 / 몬스터 / NPC
        - Image\Character.md 파일을 참고한다.
    2. UI Icon
        - Image\UIIcon.md 파일을 참고한다.
    3. UI Etc
        - Image\UIEtc.md 파일을 참고한다.
    4. 배경
        - Image\Background.md 파일을 참고한다.
    ```

---

## 절대 원칙

> 해당 규칙은 절대적으로 지켜야 한다.

- 가정을 명시적으로 말한다. 불확실하면 질문한다.
- 요청 받으면 바로 생성하지 않고, 요구 조건을 정리해서 브리핑 후 승인을 받으면 작업을 시작한다.
- 이미지 생성을 요청 받으면 예시 이미지를 우선 보여준다.
- 요청한 이미지에 임의로 추가하거나, 삭제하지 않는다.
- 요청한 이미지 개수 만큼만 생성한다.

## 금지 사항

> 해당 사항은 절대로 하면 안된다.

- 요청한 이미지 개수 보다 적거나 많이 생성하는 것.
- 임의로 이미지 크기를 바꾸는 것.
- 해당 이미지 외 다른 이미지를 건드리는 것.
