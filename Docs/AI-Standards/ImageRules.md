# 이미지 규칙

## 생성 규칙

- 개별 이미지와 시트의 크기 및 형태는 해당 카테고리 문서를 따른다.
- 전체 배경은 `Docs/Image/Background.md`를 읽는다.
- 캐릭터, 몬스터, NPC는 `Docs/Image/Character.md`를 읽는다.
- UI 아이콘은 `Docs/Image/UIIcon.md`를 읽는다.
- 기타 UI 이미지는 `Docs/Image/UIEtc.md`를 읽는다.
- 스프라이트 시트는 왼쪽에서 오른쪽으로, 위에서 아래로 채운다.

## 제작과 반영

- 제작 전에 요청 수량, 크기, 스타일, 검수 기준을 정리해 사용자에게 확인받는다.
- 참고 이미지가 있으면 함께 확인한다. 새 시안 제작도 제작 승인 범위에 포함한다.
- 제작은 사용자 또는 지정된 제작 도구에서 진행한다.
- 전달받은 결과의 수량, 크기, 파일명을 검수하고 저장 경로와 함께 보고한다.
- 프로젝트에 반영하기 전에 승인을 받는다. 기존 시트를 갱신할 경우 대상 시트도 승인 범위에 포함한다.
- 승인된 이미지와 시트만 수정하고, 시트 안의 기존 이미지와 배치는 보존한다.
