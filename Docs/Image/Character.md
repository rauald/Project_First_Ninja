# 캐릭터 이미지 규칙

> 캐릭터 이미지 생성 시 이 파일의 규칙을 지킨다.
>
> 해당 파일은 캐릭터 / 몬스터 / NPC 의 이미지 생성에 관한 내용이다.
>
> 생성 후 사용자에게 보여주고, 승인을 받으면 지정 폴더에 저장한다.

---

## 이미지 생성 규칙

> 캐릭터 / 몬스터 / NPC 공통 작업

- 같은 애니메이션의 모든 프레임은 동일한 캐릭터 스케일과 피벗을 사용한다.
- 지면 동작은 공통 바닥선에 맞춘다. 공중 동작의 높이 변화를 시트에 표현할 때는 공통 피벗을 기준으로 프레임 간 위치 변화를 유지한다.
- 한 프레임 이미지 크기는 256x256 크기로 한다.
- 스프라이트 시트는 가능한 한 정사각형에 가까운 격자로 구성한다.
- 최종 제작 프레임 수는 `열 수 × 행 수`와 같아야 한다. 모든 셀에 실제 애니메이션 프레임을 배치한다.
- 요청한 프레임 수와 선택한 격자의 셀 수가 다르면 제작 전에 최종 제작 프레임 수를 확인받는다.
- 배치 예시
  - 2프레임 → 2열×1행, 최종 2프레임
  - 4프레임 → 2열×2행, 최종 4프레임
  - 5프레임 요청에서 3열×2행을 선택 → 최종 6프레임
  - 7프레임 요청에서 4열×2행을 선택 → 최종 8프레임
  - 11프레임 요청에서 4열×3행을 선택 → 최종 12프레임
- 추가 프레임은 동작의 흐름에 맞게 그려 애니메이션에 포함한다.
- 시트 크기는 `열 수 × 256px`, `행 수 × 256px`로 계산한다.
- 시트 한 장의 최종 제작 프레임 수는 16장을 넘지 않는다.
- Loop가 돌 수 있게 만든다.
- 이미지 파일 명은 카테고리_이름_상태로 한다. (아래 예시 참고)
    - ex) Character_Miso_Idle
    - ex) Monster_Slime_Attack
    - ex) NPC_jira_Move

## 이미지 저장 규칙

> 이미지 저장은 각 카테고리 맞는 폴더에 저장한다.
- 카테고리 명
    - 캐릭터
    - 몬스터
    - NPC
- 카테고리 안에서 이름으로 폴더를 만들어 세분화 한다.
    - ex) Character/Miso
    - ex) Character/Sonogong
- 저장 폴더 : C:\Users\user\OneDrive\프로젝트\11월 개인 프로젝트\이미지\캐릭터
    - 만약 해당 카테고리의 폴더와 세분화 된 폴더가 없다면 폴더를 생성하고 해당 폴더에 저장한다.
