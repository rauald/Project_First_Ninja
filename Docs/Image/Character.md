# 캐릭터 이미지 규칙

> 캐릭터 이미지 생성 시 이 파일의 규칙을 지킨다.
>
> 해당 파일은 캐릭터 / 몬스터 / NPC 의 이미지 생성에 관한 내용이다.
>
> 생성 후 사용자에게 보여주고, 승인을 받으면 지정 폴더에 저장한다.

---

## 이미지 생성 규칙

> 캐릭터 / 몬스터 / NPC 공통 작업

- 비율을 유지하며 위아래 투명 여백 없이 높이를 채우고 가로도 같은 비율로 맞춘다.
- 한 프레임 이미지 크기는 256x256 크기로 한다.
- 스프라이트 시트의 크기가 정사각형을 최대한 유지한다. (아래 예시 참고)
    - 2프레임 : 2열 x 1행
    - 4프레임 : 2열 x 2행
    - 5프레임 : 3열 x 2행
    - 11프레임 : 4열 x 3행
- 16프레임을 넘지 않는다.
- 마지막 프레임을 투명 배경으로만 채우지 않는다.
- Loop가 돌 수 있게 만든다.
- 애니메이션으로 돌릴 때 흔들리지 않기 위해 모든 프레임의 발바닥 최하단은 y=255의 같은 바닥선에 맞춘다.
- 이미지 파일 명은 카테고리_이름_상태로 한다. (아래 예시 참고)
    - ex) Character_Miso_Idle
    - ex) Monster_Slime_Attack
    - ex) NPC_jira_Move

---

## 이미지 저장 규칙

> 이미지 저장은 각 카테고리 맞는 폴더에 저장한다.
- 카테고리 명
    - 캐릭터
    - 몬스터
    - NPC
- 카테고리 안에서 이름으로 폴더를 만들어 세분화 한다.
    - ex) Character/Miso
    - ex) Character/Sonogong
- 저장 폴더 : 경로 \이미지
    - 만약 해당 카테고리의 폴더와 세분화 된 폴더가 없다면 폴더를 생성하고 해당 폴더에 저장한다.
