# Etc 이미지 규칙

> 캐릭터 이미지 생성 시 이 파일의 규칙을 지킨다.
>
> 해당 파일은 UI Etc 이미지 생성에 관한 내용이다.
>
> 생성 후 사용자에게 보여주고, 승인을 받으면 지정 폴더에 저장한다.

---

## 이미지 생성 규칙

> UI Etc 이미지 생성 규칙

- UI에서 사용하는 Background과 Icon을 제외한 모든 이미지이다.
- Etc 이미지는 크기는 2진법으로 하지 않고, 상/하/좌/우 여백이 없는 크기로 만든다.
- 버튼 및 팝업창 배경 등은 Unity의 Sprite Border 로 늘릴 수 있으니 크게 많들지 않고, 정사각형인 32x32 또는 64x64 로 만든다.
- Etc의 스프라이트 시트는 1024x1024 크기를 유지한다.

---

## 이미지 저장 규칙

> 이미지 저장은 지정된 폴더에 저장한다.

- 다른 스프라이트 시트에 합치지 않는다. (만약 UI Icon 이랑 UI Etc 를 동시에 생성해도 Etc 는 Etc_Sceet_번호 스프라이트 시트에 합친다.)
- Etc 이미지를 생성하고, Etc의 스프라이트 시트가 이미 존재하며, 공간이 남았다면 해당 스프라이이트 시트에 합칠건지 질문한다. 스프라이트 시트가 없거나, 공간이 남아있지 않다면 스프라이트 시트를 새로 만들건지 질문한다.
- 스프라이트 시트가 정해지면 이미지를 단독으로 저장하고, 스프라이트 시트에 합친다
- 단독 이미지가 들어있는 폴더 명 (스프라이트 시트 번호랑 공유한다.)
    - Etc_번호
- Etc_번호 폴더 안의 Etc 이미지 명
    - 스프라이트 시트 이미지에 들어가 있는 이미지 순서
        - Etc_00 ~ 까지 (스프라이트 시트에 들어있는 개수 만큼)
- 스프라이트 시트 이미지
    - Etc_Sceet_번호
- 스프라이트 시트에 이미지가 가득차면 Etc_번호 다음 번호 폴더를 만들어 해당 폴더에 저장하고, Etc_Sceet_번호 도 다음 번호로 저장한다.
- 저장 폴더 : 경로 \이미지\UI
    - 만약 해당 카테고리의 폴더가 없다면 폴더를 생성하고 해당 폴더에 저장한다.
