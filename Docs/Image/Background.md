# 배경 이미지 규칙

> 배경 이미지 생성 시 이 파일의 규칙을 지킨다.
>
> 생성 후 사용자에게 보여주고, 승인을 받으면 지정 폴더에 저장한다.

---

## 이미지 생성 규칙

> 배경 작업

- 이미지 크기는 최대 2048x2048 을 넘지 않는다.
- 기준으로 잡은 해상도 크기에 맞는 이미지를 그린 후, 가로 와 세로 모두 가장 가까운 2진법 크기로 조정한다.
- 조정된 이미지 크기는 직사각형이든, 정사각형이든 상관없다.
- 조정된 이미지는 상/하/좌/우 모두 투명 여백 없어야 한다.
- 조정된 이미지가 가로 또는 세로 중 한개라도 2048의 크기가 넘어가면 생성할지 질문한다.
- 이미지 파일 명은 BG_이름 으로 한다. (아래 예시 참고)
    - ex) 타이틀 화면 배경 : BG_Title
    - ex) 로비 화면 배경 : BG_Lobby
    - ex) 인벤토리 화면 배경 : BG_Inventory

---

## 이미지 저장 규칙

> 이미지 저장은 지정된 폴더에 저장한다.

- 저장 폴더 : 경로 \이미지\BG
    - 만약 해당 폴더가 없다면 폴더를 생성하고 해당 폴더에 저장한다.
