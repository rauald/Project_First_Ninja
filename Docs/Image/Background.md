# 배경 이미지 규칙

> 배경 이미지 생성 시 이 파일의 규칙을 지킨다.
>
> 생성 후 사용자에게 보여주고, 승인을 받으면 지정 폴더에 저장한다.

---

## 이미지 생성 규칙

> 배경 작업

- 배경의 가로와 세로는 각각 최대 2048px로 한다.
- 화면 비율과 구도에 따라 정사각형 또는 직사각형을 사용한다.
- 배경 가장자리에 의도하지 않은 투명 여백이 없도록 한다.
- 프로젝트가 2의 거듭제곱 크기를 요구하면 제작 전에 크기와 비율 보정 방식을 확정한다.
- 이미지 파일 명은 BG_이름 으로 한다. (아래 예시 참고)
    - ex) 타이틀 화면 배경 : BG_Title
    - ex) 로비 화면 배경 : BG_Lobby
    - ex) 인벤토리 화면 배경 : BG_Inventory

---

## 이미지 저장 규칙

> 이미지 저장은 지정된 폴더에 저장한다.

- 저장 폴더 : C:\Users\user\OneDrive\프로젝트\11월 개인 프로젝트\이미지\배경
    - 만약 해당 폴더가 없다면 폴더를 생성하고 해당 폴더에 저장한다.
