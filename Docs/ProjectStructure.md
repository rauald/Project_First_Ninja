# 프로젝트 구조

## 1. 파일 배치 원칙
- 직접 제작한 게임 파일은 Assets/ 아래에 둔다.
- 외부 패키지와 에셋의 원본 폴더는 가능한 한 유지한다.
- 기존 파일을 확인하고 같은 역할의 파일을 중복 생성하지 않는다.

## 2. 명명 규칙
- C# 파일명은 클래스명과 일치시킨다.
- 파일과 폴더 이름은 역할을 알아볼 수 있게 작성한다.
- 자세한 코딩 규칙은 공통 Docs\AI-Standards\CSharpRules.md를 따른다.

## 5. 연결 원칙
- 입력을 읽는 부분과 게임 동작을 처리하는 부분을 분리한다.
- UI는 게임 상태를 표시하고 사용자 명령을 전달한다.
- UI 내부에 핵심 게임 규칙을 중복 작성하지 않는다.
- 구체적인 연결 방식은 기존 코드와 현재 요구사항에 맞게 정한다.
