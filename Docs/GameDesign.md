# 게임 디자인

## 1. 핵심 재미
- 플레이어가 반복해서 하고 싶어야 하는 행동: 뽑기 및 스테이지
- 그 행동에서 재미를 느끼게 할 요소: 강해지는걸 느끼고, 몬스터를 한번에 죽이는 시원시원한 느낌

## 2. 기본 플레이 흐름
1. 타이틀 화면 - 데이터 및 로컬 저장 로딩 - 로비 화면 - 플레이어 재정비 - 게임
2. 캐릭터 레벨업 및 강화, 장비 레벨업 및 강화, 스테이지 클리어
3. 캐릭터 레벨업 및 강화 시 능력치 상승, 장비 레벨업 및 강화 시 능력치 상승, 스테이지 클리어 시 재화 획득, 특성 강화 시 캐릭터 능력치 상승
4. 스테이지에 모든 몬스터를 잡을 시 클리어, 캐릭터 사망 시 실패
5. 재도전 시 현재 스테이지 재시작, 메인 메뉴 누를 시 로시 화면으로 전환

## 3. 조작
- 현재 구현할 조작 장치: Window - 방향키 및 마우스 좌클릭 / AOS - 조이스틱 방향키 및 터치
- 이동: Window - 방향키 / AOS - 조이스틱 방향키
- 주요 행동: 캐릭터 이동
- 일시정지: 환경 설정 누를 시 / 백그라운드 전환 시
- 아직 구현하지 않을 조작: 없음

최종 플랫폼이 미정이면 현재 테스트용 조작과
최종 조작의 미정 여부를 구분한다.
